# eOMS

Enterprise-grade Order Management System (OMS) foundation for multi-tenant commerce operations.

## Structure

- `Backend/` — Supabase + Drizzle ORM + Stripe services.
- `Frontend/` — Next.js App Router, Tailwind CSS, shadcn/ui, TanStack Query, Zustand.

## Goals for phase 1

- Authentication
- Organizations
- Billing
- Feature gating
- Dashboard shell
- Settings
- User management
- Enterprise design system

## Getting started

Run each workspace separately:

```bash
cd Backend
npm install
cd ../Frontend
npm install
```
